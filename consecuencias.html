Consecuencias

El acoso escolar tiene consecuencias importantes para todas las personas implicadas:

  1. Para la víctima: puede provocar miedo, ansiedad, baja autoestima o aislamiento.
  2. Para la persona agresora: puede desarrollar conductas violentas y dificultades para relacionarse.
  3. Para el grupo: se normaliza la violencia y se genera un ambiente negativo.

Por eso, es importante identificar estas situaciones y actuar a tiempo. Escucha estas experiencias:
